  • problem_number: 1 tier: level: 1 title: “The Apprentice’s Practice: Reading the Data” phenomenon_connection: “This problem models the most fundamental skill a seismologist uses: turning raw timing data from a single station into a useful distance measurement.” problem_statement: “A seismograph in Norwich, CT, detects a small tremor. The S-wave arrives 24.0 seconds after the P-wave. Using the Seismic Wave Travel-Time Graph, determine the distance from Norwich to the earthquake’s epicenter.” diagram_placeholder: “” solution: givens: - | $Time_{S-P} = 24.0 \, s$ unknowns: - | $Distance = ?$ steps: - “1. Analyze the Graph: The task is to find the distance that corresponds to a specific S-P time interval. The S-P interval is the difference in arrival time between the S-wave and P-wave, which is plotted on the y-axis.” - “2. Locate the S-P Interval: Find the 24.0-second mark on the y-axis (Time).” - “3. Find the Corresponding Distance: Move horizontally from the 24.0-second mark until you intersect the S-P lag time curve. From that intersection point, move vertically downward to the x-axis (Epicenter Distance) and read the value.” final_answer: | The epicenter is 210 km from the Norwich station.

# ————————- TIER 2: JOURNEYMAN —————————

  • problem_number: 2 tier: level: 2 title: “The Journeyman’s Task: Triangulating the Hazard” phenomenon_connection: “This problem models the actual process of locating an earthquake, using data from multiple stations to triangulate the epicenter of a tremor in the Moodus seismic area, a real-world local hazard.” problem_statement: “An earthquake occurs in the Moodus seismic area. Seismographs in three cities record the P-wave and S-wave arrival times. For each city, calculate the S-P time interval and then find the distance to the epicenter using the Travel-Time Graph.\n- Hartford, CT: P-wave arrives at 10:02:15 AM; S-wave arrives at 10:02:22 AM.\n- New Haven, CT: P-wave arrives at 10:02:20 AM; S-wave arrives at 10:02:30 AM.\n- Providence, RI: P-wave arrives at 10:02:28 AM; S-wave arrives at 10:02:44 AM.” diagram_placeholder: “” solution: givens: - “Hartford Times: $T_{P-wave} = 10:02:15$, $T_{S-wave} = 10:02:22$” - “New Haven Times: $T_{P-wave} = 10:02:20$, $T_{S-wave} = 10:02:30$” - “Providence Times: $T_{P-wave} = 10:02:28$, $T_{S-wave} = 10:02:44$” unknowns: - “S-P Interval for each city = ?” - “Distance for each city = ?” steps: - “1. Calculate S-P for Hartford:” - | $Time_{S-P} = 10:02:22 - 10:02:15 = 7.00 \, s$ - “Using the graph, a 7.00 s lag corresponds to a distance of 50.0 km.” - “2. Calculate S-P for New Haven:” - | $Time_{S-P} = 10:02:30 - 10:02:20 = 10.0 \, s$ - “Using the graph, a 10.0 s lag corresponds to a distance of 80.0 km.” - “3. Calculate S-P for Providence:” - | $Time_{S-P} = 10:02:44 - 10:02:28 = 16.0 \, s$ - “Using the graph, a 16.0 s lag corresponds to a distance of 130. km.” final_answer: | - Hartford: S-P = 7.00 s, Distance = 50.0 km - New Haven: S-P = 10.0 s, Distance = 80.0 km - Providence: S-P = 16.0 s, Distance = 130. km

# ————————- TIER 3: MASTER ——————————-

  • problem_number: 3 tier: level: 3 title: “The Master’s Insight: Forecasting from First Principles” phenomenon_connection: “This problem challenges you to think like a research scientist planning for future events. Instead of interpreting existing data, you must predict the data a new seismic station would generate, a key step in designing a better monitoring network.” problem_statement: “The New England Seismic Network wants to improve its monitoring of the Moodus area. They know a future event is likely to occur 80.0 km from New London, CT. If a P-wave from this event travels at an average speed of 6.00 km/s and an S-wave travels at 3.50 km/s, what will the S-P time interval be for a new station in New London?” diagram_placeholder: “” solution: givens: - | $Distance = 80.0 \, km$ - | $Speed_{P-wave} = 6.00 \, km/s$ - | $Speed_{S-wave} = 3.50 \, km/s$ unknowns: - | $Time_{S-P} = ?$ steps: - “1. Select Parent Equation: The equation relating distance, speed, and time is $Distance = Speed \cdot Time$.” - “2. Algebraic Rearrangement: To find the travel time for each wave, rearrange the formula to $Time = \frac{Distance}{Speed}$.” - “3. Calculate P-wave Travel Time:” - | $Time_{P-wave} = \frac{80.0 \, km}{6.00 \, km/s} = 13.33 \, s$ - “4. Calculate S-wave Travel Time:” - | $Time_{S-wave} = \frac{80.0 \, km}{3.50 \, km/s} = 22.86 \, s$ - “5. Calculate the Final S-P Interval:” - | $Time_{S-P} = Time_{S-wave} - Time_{P-wave} = 22.86 \, s - 13.33 \, s = 9.53 \, s$ final_answer: | The S-P time interval for the New London station will be 9.53 seconds.
