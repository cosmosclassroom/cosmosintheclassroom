## Key Formulas for This Set

To find the distance a wave travels:

```
Distance = Speed × Time
```

To find the time gap between wave arrivals:

```
Δt<sub>S-P</sub> = t<sub>S-wave</sub> − t<sub>P-wave</sub>
```
