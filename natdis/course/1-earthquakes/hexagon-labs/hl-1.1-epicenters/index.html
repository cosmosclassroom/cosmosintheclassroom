Hexagon Lab 1.1: Locating an Epicenter

Authors

Role: Seismologist
Mission: To determine the precise epicenter of an earthquake using seismic wave data from three monitoring stations.

Abstract

This laboratory investigation demonstrates the practical application of seismic wave analysis to locate earthquake epicenters. Using P-wave and S-wave arrival time data from three monitoring stations, students will employ standard seismological triangulation methods to determine the exact location of an earthquake’s origin.

Introduction

Seismic events generate two primary types of waves that propagate through Earth’s crust: Primary waves (P-waves) and Secondary waves (S-waves). P-waves, being compression waves, travel at higher velocities than the transverse S-waves. The time difference between these wave arrivals at various monitoring stations provides crucial data for epicenter location. This investigation utilizes real-world seismological techniques to analyze wave arrival data and determine epicenter coordinates through triangulation.

Methods and Materials

Data Collection

This investigation requires careful analysis of seismic wave arrival times from three monitoring stations. Students will calculate essential parameters and use provided reference materials to determine the earthquake’s epicenter.

Equipment

  • Travel-Time Graph
  • Compass
  • Reference Map
  • Data Recording Sheet

Procedure

Part 1: Wave Analysis

Calculate the S-P wave interval and determine epicenter distances for each monitoring station.

1.1 S-P Interval Calculation

For each monitoring station, calculate the time difference between P-wave and S-wave arrivals using the following formula:

S-P Interval = S-wave arrival time - P-wave arrival time

1.3 Distance Determination

Using the Travel-Time Graph (Figure 2):

Figure 2: Seismic wave travel-time curves showing the linear relationship between arrival times and epicenter distance. P-waves (blue) arrive first due to higher propagation velocity, while S-waves (red) arrive later. The increasing separation between curves with distance enables accurate epicenter determination using the S-P interval method.

Follow these steps to determine epicenter distance:

  1. Locate the calculated S-P Interval on the vertical axis
  2. Move horizontally to the center point between S-wave and P-wave curves
  3. Project vertically down to the horizontal axis
  4. Record the corresponding distance in kilometers

Part 2: Epicenter Triangulation

2.1 Map Preparation

Transfer the reference map (Figure 1) to your laboratory notebook. This map displays the locations of monitoring stations (City A, B, and C) with an appropriate scale bar for distance measurements.

Figure 1: Schematic representation of monitoring station locations on a reference grid. Scale bar indicates distances in kilometers (km).

2.2 Triangulation Process

  1. For each monitoring station:
    • Set compass radius to the calculated epicenter distance
    • Center compass on the station location
    • Draw a complete circle representing possible epicenter positions
  2. Epicenter Identification:
    • Locate the intersection point of all three circles
    • Mark this point with an “X” and label as “Epicenter”
    • Record the coordinates using the reference grid

Results

Document your findings in your laboratory notebook, including:

  • Completed data table with all calculations
  • Annotated map showing triangulation circles
  • Final epicenter coordinates

Discussion

Consider the following questions:

  1. How does the time difference between P-waves and S-waves help determine distance?
  2. Why are three stations necessary for accurate epicenter location?
  3. What factors might affect the precision of this method?
