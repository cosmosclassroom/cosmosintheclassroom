Unit 3 Test: The Siege of Constantinople — Answer Key

Part 1: The Apprentice’s Practice

  1. b) Its vertical velocity is zero, but its horizontal velocity is non-zero.
  2. b) 45°
  3. c) 11 m/s

Part 2: The Journeyman’s Task

  1. Trebuchet: $v_0 = 45.0~\text{m/s}$, $\theta = 50.0^\circ$

a) [ v_{x,i} = v_0 \cos\theta = 45.0~\text{m/s} \times \cos(50.0^\circ) = 28.96~\text{m/s} ] [ v_{y,i} = v_0 \sin\theta = 45.0~\text{m/s} \times \sin(50.0^\circ) = 34.49~\text{m/s} ]

b) [ t = \frac{2 v_{y,i}}{|\vec{a}_g|} = \frac{2 \times 34.49~\text{m/s}}{9.80~\text{m/s}^2} = 7.04~\text{s} ]

c) [ h_{max} = \frac{v_{y,i}^2}{2|\vec{a}_g|} = \frac{(34.49~\text{m/s})^2}{2 \times 9.80~\text{m/s}^2} = 60.7~\text{m} ]

d) [ R = v_{x,i} \cdot t = 28.96~\text{m/s} \times 7.04~\text{s} = 204~\text{m} ]

  1. Skiff: $d = 300.0~\text{m}$, $v_{skiff} = 2.50~\text{m/s}$, $v_{current} = 1.00~\text{m/s}$

a) [ v_{res} = \sqrt{(2.50~\text{m/s})^2 + (1.00~\text{m/s})^2} = \sqrt{6.25 + 1.00} = \sqrt{7.25} = 2.69~\text{m/s} ] Direction: [ \theta = \tan^{-1}\left(\frac{1.00}{2.50}\right) = 21.8^\circ \text{ downstream} ]

b) [ t = \frac{300.0~\text{m}}{2.50~\text{m/s}} = 120.0~\text{s} ]

c) [ x = v_{current} \cdot t = 1.00~\text{m/s} \times 120.0~\text{s} = 120.0~\text{m} ]

Part 3: The Master’s Insight

  1. Cannon: $v_0 = 160.0~\text{m/s}$, $\theta = 45.0^\circ$, $d = 1600~\text{m}$, $v_{tower} = 1.50~\text{m/s}$

a) [ R = \frac{v_0^2 \sin(2\theta)}{|\vec{a}_g|} = \frac{(160.0~\text{m/s})^2 \sin(90^\circ)}{9.80~\text{m/s}^2} = \frac{25600~\text{m}^2/\text{s}^2}{9.80~\text{m/s}^2} = 2612~\text{m} ] Yes, this is sufficient to hit a target 1600 m away.

b) [ t = \frac{2 v_0 \sin\theta}{|\vec{a}_g|} = \frac{2 \times 160.0~\text{m/s} \times \sin(45.0^\circ)}{9.80~\text{m/s}^2} ] [ = \frac{2 \times 160.0~\text{m/s} \times 0.7071}{9.80~\text{m/s}^2} = \frac{226.27~\text{m/s}}{9.80~\text{m/s}^2} = 23.1~\text{s} ]

c) [ d_{tower} = v_{tower} \cdot t = 1.50~\text{m/s} \times 23.1~\text{s} = 34.7~\text{m} ] [ \theta_{comp} = \tan^{-1}\left(\frac{34.7~\text{m}}{1600~\text{m}}\right) = 1.24^\circ ] The cannoneer must aim the barrel $1.24^\circ$ backward (relative to the direct line to the target) to compensate for the tower’s motion.
