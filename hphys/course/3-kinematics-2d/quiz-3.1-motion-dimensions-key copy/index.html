Quiz 3.1: Motion in Two Dimensions — Answer Key

Part 1: Conceptual Understanding

  1. b) The horizontal motion is independent of the vertical motion.
  2. a) Zero
  3. d) Trigonometric functions

Part 2: Short Answer

  1. Time of flight depends only on initial vertical velocity and height because the vertical motion determines how long the projectile stays in the air. The horizontal velocity affects only the range, not the time aloft.

  2. Diagram: A projectile launched at angle $\theta$ with initial velocity $v_0$:

    • $v_{0x} = v_0 \cos\theta$ (horizontal component)
    • $v_{0y} = v_0 \sin\theta$ (vertical component)

Part 3: Problem Solving

  1. Soccer ball: $v_0 = 18.0~\text{m/s}$, $\theta = 35.0^\circ$

a) [ v_{0x} = v_0 \cos\theta = 18.0~\text{m/s} \times \cos(35.0^\circ) = 14.75~\text{m/s} ] [ v_{0y} = v_0 \sin\theta = 18.0~\text{m/s} \times \sin(35.0^\circ) = 10.33~\text{m/s} ]

b) [ t = \frac{2 v_{0y}}{|\vec{a}_g|} = \frac{2 \times 10.33~\text{m/s}}{9.80~\text{m/s}^2} = 2.11~\text{s} ]

c) [ h_{max} = \frac{v_{0y}^2}{2|\vec{a}_g|} = \frac{(10.33~\text{m/s})^2}{2 \times 9.80~\text{m/s}^2} = 5.44~\text{m} ]

d) [ R = v_{0x} \cdot t = 14.75~\text{m/s} \times 2.11~\text{s} = 31.1~\text{m} ]

  1. Rock from balcony: $h = 12.0~\text{m}$, $v_{0x} = 6.0~\text{m/s}$

a) [ 12.0~\text{m} = \frac{1}{2} \times 9.80~\text{m/s}^2 \times t^2 ] [ t^2 = \frac{12.0~\text{m}}{4.90~\text{m/s}^2} = 2.45~\text{s}^2 ] [ t = 1.57~\text{s} ]

b) [ x = v_{0x} t = 6.0~\text{m/s} \times 1.57~\text{s} = 9.4~\text{m} ]

Part 4: Synthesis

  1. Example: A rescue helicopter drops supplies to a moving boat. To ensure the package lands on the boat, the pilot must analyze both the horizontal motion of the boat and the vertical motion of the package, breaking the motion into components and solving for the correct release point.
