Problem Set 2.1: Graphical Analysis of Motion - Answer Key

Part A: The Apprentice’s Practice - Foundational Skills

Problem 1: Walking to School

a) Average velocity between t = 120 s and t = 480 s:

  • At t = 120 s: position = 180 m
  • At t = 480 s: position = 720 m
  • $v_{avg} = \frac{\Delta x}{\Delta t} = \frac{720 - 180}{480 - 120} = \frac{540}{360} = 1.5 \text{ m/s}$

b) Distance traveled in first 240 s:

  • At t = 0 s: position = 0 m
  • At t = 240 s: position = 360 m
  • Distance traveled = 360 m

c) Displacement after 600 s:

  • Initial position = 0 m
  • Final position = 900 m
  • Displacement = 900 m

Problem 2: Bicycle Ride Analysis

a) Acceleration between t = 4.0 s and t = 10.0 s:

  • At t = 4.0 s: velocity = 6.0 m/s
  • At t = 10.0 s: velocity = 15.0 m/s
  • $a = \frac{\Delta v}{\Delta t} = \frac{15.0 - 6.0}{10.0 - 4.0} = \frac{9.0}{6.0} = 1.5 \text{ m/s}^2$

b) Displacement during first 8.0 s (area under curve):

  • The v-t graph is a triangle from t = 0 to t = 8.0 s
  • Base = 8.0 s, height = 12.0 m/s
  • Area = $\frac{1}{2} \times 8.0 \times 12.0 = 48.0 \text{ m}$

c) Velocity at t = 16.0 s:

  • Acceleration = 1.5 m/s² (constant from the linear graph)
  • $v = v_0 + at = 0 + (1.5)(16.0) = 24.0 \text{ m/s}$

Problem 3: Elevator Motion

a) Time intervals when elevator is accelerating:

  • t = 0 to 2 s (velocity increasing from 0 to 4.0 m/s)
  • t = 10 to 14 s (velocity decreasing from 4.0 to 0 m/s)
  • t = 14 to 18 s (velocity decreasing from 0 to -2.0 m/s)

b) Acceleration between t = 10.0 s and t = 14.0 s:

  • At t = 10.0 s: velocity = 4.0 m/s
  • At t = 14.0 s: velocity = 0 m/s
  • $a = \frac{0 - 4.0}{14.0 - 10.0} = \frac{-4.0}{4.0} = -1.0 \text{ m/s}^2$

c) Total displacement from t = 0 to t = 20.0 s:

  • Phase 1 (0-2 s): Triangle area = $\frac{1}{2} \times 2 \times 4 = 4.0 \text{ m}$
  • Phase 2 (2-10 s): Rectangle area = $4.0 \times 8 = 32.0 \text{ m}$
  • Phase 3 (10-14 s): Triangle area = $\frac{1}{2} \times 4 \times 4 = 8.0 \text{ m}$
  • Phase 4 (14-16 s): No movement = 0 m
  • Phase 5 (16-20 s): Rectangle area = $2.0 \times 4 = 8.0 \text{ m}$ (downward)
  • Total displacement = 4.0 + 32.0 + 8.0 + 0 - 8.0 = 36.0 m upward

Part B: The Journeyman’s Task - Synthesis & Application

Problem 4: Rocket Telemetry Analysis

a) Engine burn acceleration:

  • Engine burns from t = 0 to t = 25 s (linear increase in velocity)
  • $a = \frac{480 - 0}{25 - 0} = \frac{480}{25} = 19.2 \text{ m/s}^2$

b) Ballistic phase acceleration:

  • From t = 25 s to t = 50 s
  • $a = \frac{235 - 480}{50 - 25} = \frac{-245}{25} = -9.8 \text{ m/s}^2$

c) Engine cutoff time:

  • Engine cuts off at t = 25 s
  • Evidence: At t = 25 s, the velocity pattern changes from linear increase to linear decrease, and the acceleration changes from +19.2 m/s² to -9.8 m/s²

d) Time to reach apogee:

  • Using ballistic phase: $v = v_0 + at$
  • At apogee: $0 = 480 + (-9.8) \times \Delta t$
  • $\Delta t = \frac{480}{9.8} = 49.0 \text{ s after engine cutoff}$
  • Apogee occurs at: t = 25 + 49.0 = 74.0 s after launch

e) Performance comparison:

  • This rocket: 480 m/s at engine cutoff (t = 25 s)
  • Lab rocket: 784 m/s at engine cutoff (t = 20 s)
  • The lab rocket achieved higher velocity at engine cutoff and would reach a higher altitude.

Part C: The Master’s Insight - Metacognitive Reflection

Problem 5: Motion Detective Challenge

a) Velocity-time graph construction: Calculate velocity as slope between adjacent points:

  • t = 0-2 s: $v = \frac{8.0-0}{2} = 4.0 \text{ m/s}$
  • t = 2-4 s: $v = \frac{14.4-8.0}{2} = 3.2 \text{ m/s}$
  • t = 4-6 s: $v = \frac{19.2-14.4}{2} = 2.4 \text{ m/s}$
  • t = 6-8 s: $v = \frac{22.4-19.2}{2} = 1.6 \text{ m/s}$
  • t = 8-10 s: $v = \frac{24.0-22.4}{2} = 0.8 \text{ m/s}$
  • t = 10-12 s: $v = \frac{24.0-24.0}{2} = 0.0 \text{ m/s}$
  • t = 12-14 s: $v = \frac{22.4-24.0}{2} = -0.8 \text{ m/s}$
  • t = 14-16 s: $v = \frac{19.2-22.4}{2} = -1.6 \text{ m/s}$

b) Acceleration-time graph: Calculate acceleration as change in velocity:

  • Most intervals show $a = -0.8 \text{ m/s}^2$ (approximately -0.8 m/s²)
  • This is close to $-\frac{a_g}{12} = -0.82 \text{ m/s}^2$ suggesting scaled motion

c) Type of motion:

  • This represents vertical projectile motion (object thrown upward)
  • The constant negative acceleration (~-0.8 m/s²) suggests either:
    • Scaled-down gravity for demonstration purposes, OR
    • Motion in reduced gravity environment
  • Pattern matches projectile: positive initial velocity, constant negative acceleration, reaches peak, returns

d) Maximum height:

  • Object reaches maximum height at t = 10-12 s when velocity = 0
  • Position at maximum height = 24.0 m

Reflection Question (Sample Response):

How does a single velocity-time graph contain complete information about one-dimensional motion?

A velocity-time graph contains complete motion information because: (1) the y-values directly show velocity at each moment, (2) the slope at any point gives acceleration, and (3) the area under the curve gives displacement. For example, in the bicycle problem, I could read the velocity directly, calculate acceleration from the slope (1.5 m/s²), and find displacement from the triangular area under the curve (48 m). This single graph type allows you to reconstruct the entire motion story.

Key Concepts Reinforced:

  • Graphical Analysis: Students interpret slopes and areas of motion graphs
  • Kinematics: Multiple applications of $a = \frac{\Delta v}{\Delta t}$ and displacement calculations
  • Pattern Recognition: Identifying different motion types from graph shapes
  • Scientific Reasoning: Using mathematical analysis to infer physical processes
