Assessments Directory

This directory contains assessment files for the course.

Structure

  • HTML files in this directory will be committed to the repository and published
  • Markdown assessment files with quiz-.md and test-.md patterns are ignored by git
  • Sample assessments are included as reference

Creating New Assessments

To create a new assessment:

  1. Copy the sample assessment template
  2. Follow the Markdown assessment format documented in docs/markdown-assessments.md
  3. Use the assessment-md layout in the frontmatter
  4. Name private assessments with quiz- or test- prefix to keep them out of the repository

Testing Assessments

Run the Jekyll server locally to preview assessments before deploying.
