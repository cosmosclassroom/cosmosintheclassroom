Lab Creation Guidelines

Investigation Design Principles

  1. Phenomenon-Driven: Each investigation should connect clearly to the unit’s anchoring phenomenon
  2. Progressive Complexity: Investigations should build in sophistication throughout the lab
  3. Authentic Analysis: Use real or realistic data that requires genuine scientific reasoning
  4. Multiple Representations: Include opportunities for students to work with graphs, equations, and conceptual models

Claim-Evidence-Reasoning Structure

  • Claim: A conclusion that answers the scientific question
  • Evidence: Specific data from the investigation that supports the claim
  • Reasoning: Scientific principles that explain why the evidence supports the claim

Data Quality Standards

  • All numerical data should include appropriate units
  • Significant figures should reflect realistic measurement precision
  • Datasets should be large enough to identify clear patterns
  • Include some uncertainty or variability to promote discussion of experimental limitations

Assessment Integration

Each lab should clearly connect to:

  • Unit learning objectives from the course JSON
  • Crosscutting concepts (thinking lenses)
  • Science and engineering practices
  • The unit’s overarching question
