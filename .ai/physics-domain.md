# Physics Domain Knowledge - AI Assistant Guide

## 🔬 **Physics Content Validation**

### **Common Physics Errors to Catch**
- **Units**: Missing units, incorrect unit conversions, dimensional analysis errors
- **Equations**: Wrong formulas, sign errors, vector vs scalar confusion  
- **Concepts**: Force vs acceleration confusion, energy vs power mix-ups
- **Math**: Significant figures, scientific notation, rounding errors

### **Key Physics Relationships**
```
Mechanics: F=ma, KE=½mv², PE=mgh, p=mv
Electricity: V=IR, P=VI, Q=CV, F=qE
Waves: v=fλ, f=1/T, E=hf
Thermodynamics: PV=nRT, Q=mcΔT
```

### **Standard Problem-Solving Format**
1. **Given**: List known values with units
2. **Find**: Identify what to solve for
3. **Equations**: Write relevant formulas
4. **Solve**: Step-by-step calculation
5. **Check**: Units, reasonableness, significant figures

## 🧠 **Cognitive Load Guidelines**

### **Information Processing Limits**
- **Working Memory**: 3-4 new concepts per lesson maximum
- **Chunking**: Group related information together
- **Prerequisites**: Always check prior knowledge before introducing new concepts
- **Scaffolding**: Build complexity gradually with multiple examples

### **Visual Representation Rules**
- **Diagrams**: Always label forces, use consistent symbols
- **Graphs**: Include axes labels, units, and scales
- **Equations**: Use LaTeX formatting for clarity
- **Color Coding**: Consistent color scheme for forces, energy types

### **Common Student Misconceptions**
- **Motion**: "Objects need force to maintain motion" (Newton's 1st law)
- **Energy**: "Energy can be created or destroyed" (conservation)
- **Electricity**: "Current is used up in a circuit" (conservation of charge)
- **Heat**: "Heat and temperature are the same" (thermal concepts)
- **Waves**: "Sound and light are the same type of wave" (mechanical vs EM)
