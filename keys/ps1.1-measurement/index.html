Problem Set 1.1: The Language of Measurement - Answer Key

Part A: Foundational Skills

Dimensional Analysis

  1. Cheetah’s Speed
    The cheetah’s speed is 33.33 m/s.
    Work: \(\frac{120.0\ \text{km}}{1\ \text{hr}} \times \frac{1000\ \text{m}}{1\ \text{km}} \times \frac{1\ \text{hr}}{3600\ \text{s}} = 33.333\ldots\ \text{m/s}\) Significant Figures: The initial measurement (120.0 km/hr) has four significant figures, so the answer is reported to four significant figures.

  2. Basketball Hoop Height
    The hoop’s height is 3.048 m.
    Work: \(10.00\ \text{ft} \times \frac{12\ \text{in}}{1\ \text{ft}} \times \frac{2.540\ \text{cm}}{1.000\ \text{in}} \times \frac{1\ \text{m}}{100\ \text{cm}} = 3.048\ \text{m}\) Significant Figures: The initial measurement (10.00 ft) and the conversion factor (2.540 cm) both have four significant figures. Other conversions are exact definitions. Report to four significant figures.

  3. Marathon Distance
    The marathon distance is 42.19 km.
    Work: \(26.22\ \text{mi} \times \frac{1.609\ \text{km}}{1.000\ \text{mi}} = 42.19338\ \text{km}\) Significant Figures: Both the initial measurement (26.22 mi) and the conversion factor (1.609 km) have four significant figures, so round to four significant figures.

Significant Figures

  1. Area of Land
    The area is 2.0 × 10^2 m^2 (or 200 m^2, reported to two significant figures).
    Work: \(\text{Area} = \text{length} \times \text{width} = 24.5\ \text{m} \times 8.2\ \text{m} = 200.9\ \text{m}^2\) Rule: When multiplying, the answer must have the same number of significant figures as the measurement with the fewest significant figures. The width (8.2 m) has two, so round to two significant figures.

  2. Total Displacement
    The total displacement is 123 m.
    Work: \(15.88\ \text{m} + 2.1\ \text{m} + 105\ \text{m} = 122.98\ \text{m}\) Rule: When adding, round to the same number of decimal places as the measurement with the fewest decimal places. The measurement 105 m has zero decimal places, so round to the nearest whole number.

  3. Dividing Measurements
    The result is 2.7 × 10^2 (or 270).
    Work: \(\frac{150.0\ \text{s}}{0.55\ \text{s}} = 272.7272\ldots\) Rule: When dividing, the answer must have the same number of significant figures as the measurement with the fewest significant figures. The time 0.55 s has two significant figures, so round to two significant figures.

Part B: Application & Synthesis

The distance between Syene and Alexandria is 925 km.

Work: \(5.00 \times 10^3\ \text{stadia} \times \frac{185\ \text{m}}{1\ \text{stadium}} \times \frac{1\ \text{km}}{1000\ \text{m}} = 925\ \text{km}\)

Significant Figures: The distance in stadia (5.00 × 10^3) and the conversion factor (185 m) both have three significant figures. Report the final answer with three significant figures.

Part C: Reflection

Reporting the distance as 925.1234 km would be scientifically dishonest because it implies a level of precision not supported by the original measurements. The input values used in the calculation (5.00 × 10^3 stadia and 185 m) each have only three significant figures. This means we are confident only to the nearest whole kilometer. Extra calculator digits are meaningless artifacts and do not represent measured information. Honest scientific communication requires reporting only the digits of which can can be reasonably certain.
