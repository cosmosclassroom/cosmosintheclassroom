Unit 1: The Invisible Currents

This directory contains all materials for the Standard Physics Unit 1: “The Invisible Currents”. The content is organized into the following folders:

Note: The 1-forecast/ and ose-import/ directories are from an older organization structure. All content has been migrated to the new directory structure below. Please use the new structure for any future content development.

Directory Structure

  • data/: Contains data files used by labs and activities
    • Includes JSON data, formatted HTML data tables, and visualization resources
    • Data files are referenced by the hexagon labs and problem sets
  • flexbook/: Contains the core textbook chapters for the unit
    • fb-1.1-electrical-concepts.md: Main chapter on electrical concepts and energy grids
  • hexagon-labs/: Contains inquiry-based lab activities
    • hl-1.1-blackout-narratives.md: Lab analyzing power outage scenarios and impacts
    • hl-1.2-power-strip-dissection.md: Lab examining how power strips work and circuit design
  • keys/: Contains answer keys for assessments
    • ps-1.1-circuits-power-key.md: Answer key for the circuits and power problem set
  • lectures/: Contains lecture materials and slides
    • lec-1.1-circuits-power.md: Lecture notes on circuits and power concepts
    • lec-1.1-circuits-power.html: HTML version of the lecture for presentation
  • problem-sets/: Contains practice problem sets and assessments
    • ps-1.1-circuits-power.md: Current problem set on circuits and power relationships
    • ps-1.1-circuits-original.md: Original version of the problem set (archive)
  • research-briefs/: Contains guided research activities and projects
    • rb-1.1-grid-reliability.md: Research brief on energy grid reliability issues

Note on Document Format

  • All materials are written in Markdown with specific formatting for student accessibility
  • Hexagon Labs are designed to be completed in student science notebooks
  • Problem Sets are designed to be completed on separate paper for submission
  • Research Briefs include scaffolded sections for student research documentation

Naming Convention

Files follow this naming convention:

  • fb-1.1-topic.md: Flexbook chapter (unit#.chapter#)
  • hl-1.1-topic.md: Hexagon Lab (unit#.activity#)
  • ps-1.1-topic.md: Problem Set (unit#.set#)
  • rb-1.1-topic.md: Research Brief (unit#.brief#)
  • lec-1.1-topic.md: Lecture notes (unit#.lecture#)
