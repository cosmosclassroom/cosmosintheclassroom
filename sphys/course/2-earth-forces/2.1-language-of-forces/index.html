Essential Questions:

  1. What is a force in physics?
  2. How do vectors differ from scalars, and why are forces vectors?
  3. How can we visually represent all the forces acting on an object using a Free-Body Diagram (FBD)?

What is a Force?

  • A Force is simply a push or a pull exerted on an object by another object.
  • Forces cause changes in motion (acceleration). If an object’s velocity is changing, there must be a net force acting on it.
  • Forces are interactions. They always come in pairs (Newton’s 3rd Law, which we’ll visit later).
  • Unit of Force: Newton (N). $1$ N $= 1$ kg$\cdot$m/s$^2$.

Scalars vs. Vectors

  • Scalar: A quantity described only by its magnitude (size).
    • Examples: Mass (5 kg), Temperature (20 °C), Speed (30 m/s), Time (10 s).
  • Vector: A quantity described by both magnitude and direction.
    • Examples: Velocity (30 m/s, East), Acceleration (-9.8 m/s², Down), Displacement (5 m, North).

Why are Forces Vectors?

  • The effect of a push or pull depends critically on its direction. A 10 N push East has a different effect than a 10 N push North.
  • We represent vectors graphically as arrows:
    • Length of arrow $\propto$ Magnitude
    • Arrowhead indicates Direction

Representing Force Vectors

  • Graphically: Draw arrows. Head-to-tail addition finds the resultant (net) vector.
  • Notation: We use an arrow symbol above the variable: $\vec{F}$. Magnitude is often written without the arrow: $F$.
  • Components: In 1D, we use +/- signs (e.g., $\vec{F}_1 = +10$ N, $\vec{F}_2 = -5$ N).
  • Net Force ($\vec{F}_{net}$ or $\Sigma \vec{F}$): The vector sum of all forces acting on an object.

Sign Convention:

  • Positive (+): North, East, Up
  • Negative (-): South, West, Down

Force Vector Notation

Key Points:

  • Arrow length ∝ Magnitude
  • Arrow direction shows force direction
  • Multiple forces can act on one object

Force Magnitude Comparison

Key Points:

  • Longer arrows = stronger forces
  • Same direction forces add together
  • Relative sizes matter for net effect

Vector Addition: Head-to-Tail Method

Key Steps:

  1. Place first vector tail at origin
  2. Place second vector tail at first vector’s head
  3. Net vector goes from origin to final head

Example: $\vec{F}_{net} = \vec{F}_1 + \vec{F}_2 = (+10) + (-5) = +5$ N

Step 1: Place First Vector

Start at origin

  • Place tail of first vector at (0,0)
  • Arrow shows magnitude and direction

Step 2: Add Second Vector (Head-to-Tail)

Connect the vectors

  • Place tail of second vector at head of first
  • This is the “head-to-tail” method

Step 3: Draw Net Vector

Find the resultant

  • Draw arrow from origin to final head
  • This is your net force vector!

The Resultant Vector

Definition: The resultant vector (or net vector) is the single vector that represents the combined effect of all individual vectors acting on an object.

  • Symbol: $\vec{F}{net}$ or $\vec{F}{resultant}$ or $\Sigma \vec{F}$
  • Physical Meaning: The resultant force determines the object’s acceleration
  • Key Principle: $\vec{F}_{resultant} = \vec{F}_1 + \vec{F}_2 + \vec{F}_3 + …$

Adding Vectors: The Basics

Simple Case - Same Direction:

  • When forces act in the same direction, simply add their magnitudes
  • Example: 3 N East + 2 N East = 5 N East

Opposite Directions:

  • When forces oppose each other, add opposite sign
  • Example: 5 N East + 3 N West = 5 N - 3 N = 2 N East

The key: Use + and - signs to track direction!

1D Vector Addition Examples

Example 1: Tectonic Forces Acting East

  • Slab Pull: $+3.0 \times 10^{13}$ N (East)
  • Ridge Push: $+1.5 \times 10^{13}$ N (East)
  • Result: $\vec{F}_{net} = (+3.0) + (+1.5) = +4.5 \times 10^{13}$ N East

Example 2: Opposing Forces

  • Eastward Force: $+2.8 \times 10^{13}$ N
  • Westward Resistance: $-1.2 \times 10^{13}$ N
  • Result: $\vec{F}_{net} = (+2.8) + (-1.2) = +1.6 \times 10^{13}$ N East

2D Vector Addition: When Forces are Perpendicular

New Challenge: What if forces act at 90° angles?

Solution: Use the Pythagorean theorem! \(F_{net} = \sqrt{F_x^2 + F_y^2}\)

Example:

  • East Force: $F_x = 3.0 \times 10^{12}$ N
  • North Force: $F_y = 4.0 \times 10^{12}$ N
  • Result: $F_{net} = \sqrt{3^2 + 4^2} = \sqrt{25} = 5.0 \times 10^{12}$ N

This is the famous 3-4-5 right triangle!

Working Backwards: Finding Unknown Forces

Real-World Scenario: Scientists measure the net motion but need to find what’s causing it.

The Process:

  1. Measure the net force (from motion data)
  2. Identify known forces (from models)
  3. Calculate the unknown force

Equation: $\vec{F}{unknown} = \vec{F}{net} - \vec{F}_{known}$

Example: If net = -5.0 × 10¹³ N and known = +2.0 × 10¹³ N Then unknown = (-5.0) - (+2.0) = -7.0 × 10¹³ N

Summary: Key Formulae for Vector Addition

1D Forces (same or opposite directions): \(\vec{F}_{net} = \vec{F}_1 + \vec{F}_2\)

2D Perpendicular Forces: \(F_{net} = \sqrt{F_x^2 + F_y^2}\)

Finding Unknown Forces: \(\vec{F}_{unknown} = \vec{F}_{net} - \vec{F}_{known}\)

But Wait - How Do We Identify All the Forces?

The Challenge: Before we can add vectors, we need to know what forces are acting on an object.

The Solution: Free-Body Diagrams (FBDs)

Why FBDs Matter:

  • They force us to think systematically about ALL forces
  • They provide a clear visual starting point for calculations
  • They prevent us from missing important forces

Free-Body Diagrams (FBDs)

Purpose: Isolate one object and visualize all external forces acting ON it.

Steps:

  1. Isolate: Draw the object
  2. Identify Forces: Find all interactions
  3. Draw Arrows: From object center
  4. Label: Name each force vector

Putting It All Together: From Concepts to Tectonic Applications

The Big Picture:

  1. Identify Forces → Use your knowledge of plate interactions
  2. Draw FBD → Isolate one plate, show all forces as arrows
  3. Apply Math → Use the vector addition rules you just learned
  4. Interpret Result → What does the net force tell us about plate motion?

Real Example: A subducting plate might experience slab pull (down), ridge push (horizontal), and mantle drag (opposing). Your job: find the net effect!

FBD Example: Tectonic Plate (Conceptual)

Let’s think about a piece of oceanic crust being subducted:

  1. Object: The oceanic plate section. (Draw a rectangle).
  2. Forces:
    • Gravity ($\vec{F}_g$ or Slab Pull): Pulling the dense plate down into the mantle (Down & Right). Strong force.
    • Push from Ridge ($\vec{F}_{push}$): Force from the mid-ocean ridge (Right). Moderate force.
    • Mantle Drag ($\vec{F}_{drag}$): Resistance from the mantle below (Left). Moderate force.
    • Buoyancy ($\vec{F}_{B}$): Upward force from displaced mantle (Up & Left). Weaker force.
    • (Maybe friction with overriding plate, etc.)
  3. Draw & Label: Key Idea: The net force (vector sum of all these arrows) determines how the plate accelerates.

FBD Example: Tectonic Plate (Visualization)

Key Forces Acting on a Subducting Oceanic Plate:

  • Slab Pull (gravity): ~8.5 × 10¹² N - Down and Right
  • Ridge Push: ~3.2 × 10¹² N - Right
  • Mantle Drag (resistance): ~4.1 × 10¹² N - Left
  • Buoyancy: ~2.8 × 10¹² N - Up and Left

All forces shown would emanate from the plate center in a proper FBD. Arrow length would be proportional to force magnitude.

Check for Understanding

Question: You push a book East across a table with a force of 5 N. Friction pushes West with 3 N. Draw the FBD (top-down view) and find the net force.

Solution:

  • FBD shows $\vec{F}{\mathrm{push}} = +5~\mathrm{N}$ (East arrow) and $\vec{F}{\mathrm{friction}} = -3~\mathrm{N}$ (West arrow, shorter).
  • $\vec{F}_{\mathrm{net}} = (+5~\mathrm{N}) + (-3~\mathrm{N}) = +2~\mathrm{N}$ (East).

Both force vectors emanate from the book’s center, with the push force being a longer arrow than the friction force.

Check for Understanding: 2D Forces

Question: A tectonic plate experiences two perpendicular forces:

  • 6 N North
  • 8 N East

What is the magnitude of the net force?

Solution:

  • Use Pythagorean theorem: $F_{net} = \sqrt{F_x^2 + F_y^2}$
  • $F_{net} = \sqrt{(8)^2 + (6)^2} = \sqrt{64 + 36} = \sqrt{100} = 10$ N
  • Answer: 10 N (Another classic 6-8-10 right triangle!)

Answering Our Essential Questions

  1. What is a force?
    • A push or a pull exerted by one object on another, measured in Newtons (N).
  2. Vectors vs. Scalars?
    • Scalars have magnitude only (mass, speed). Vectors have magnitude AND direction (force, velocity). Forces are vectors because direction matters.
  3. What is an FBD?
    • A diagram showing one object and all external forces acting on it, represented as labeled arrows. It’s the starting point for analyzing forces.
