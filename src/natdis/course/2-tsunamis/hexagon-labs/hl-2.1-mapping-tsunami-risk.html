Template Usage Instructions

Data Authenticity Standards:

  • Use real datasets when possible, simplified appropriately for grade level
  • Include actual citations and context
  • Show realistic uncertainties and limitations
  • Connect to current/recent events when relevant

Role-Specific Analysis:

  • Scientist Labs: Focus on pattern recognition, measurement critique, uncertainty analysis
  • Engineer Labs: Focus on optimization, trade-off analysis, constraint management
  • Policymaker Labs: Focus on stakeholder analysis, multi-criteria decisions, political feasibility

Methodology Critique Framework:

  • Always include “Critical Thinking” checkpoints before analysis
  • Require explicit evaluation of data limitations and assumptions
  • Connect methodological weaknesses to real-world consequences
  • Address both technical and political sources of information breakdown

Validation Checklist:

  • Uses authentic data sources with proper attribution
  • Includes realistic constraints and limitations
  • Requires both pattern recognition and critical evaluation
  • Connects to previous labs in the role sequence
  • Addresses system vulnerabilities specific to the role
  • Provides clear information for next role in sequence
  • Includes local (Branford) application
