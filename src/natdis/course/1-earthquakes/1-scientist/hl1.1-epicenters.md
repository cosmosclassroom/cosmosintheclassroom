## Authors

**Role:** Seismologist  
**Mission:** To determine the precise epicenter of an earthquake using seismic wave data from three monitoring stations.

## Abstract

This laboratory investigation demonstrates the practical application of seismic wave analysis to locate earthquake epicenters. Using P-wave and S-wave arrival time data from three monitoring stations, students will employ standard seismological triangulation methods to determine the exact location of an earthquake's origin.

## Introduction

Seismic events generate two primary types of waves that propagate through Earth's crust: Primary waves (P-waves) and Secondary waves (S-waves). P-waves, being compression waves, travel at higher velocities than the transverse S-waves. The time difference between these wave arrivals at various monitoring stations provides crucial data for epicenter location. This investigation utilizes real-world seismological techniques to analyze wave arrival data and determine epicenter coordinates through triangulation.

#### 1.1 S-P Interval Calculation

For each monitoring station, calculate the time difference between P-wave and S-wave arrivals using the following formula:

```math
S-P Interval = S-wave arrival time - P-wave arrival time
```

#### 2.2 Triangulation Process

1. For each monitoring station:
   - Set compass radius to the calculated epicenter distance
   - Center compass on the station location
   - Draw a complete circle representing possible epicenter positions

2. Epicenter Identification:
   - Locate the intersection point of all three circles
   - Mark this point with an "X" and label as "Epicenter"
   - Record the coordinates using the reference grid
