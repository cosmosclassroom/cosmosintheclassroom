Development Tools

Local development tools for the Socrates educational platform.

Note: These tools run locally outside the Jekyll site. To access them:
  1. Navigate to the tools directory in your file system
  2. Open the HTML files directly in your browser
🔧 Ratatoskr Dashboard

Complete system architecture and dashboard for managing course content, student progress, and educational analytics.

Location: e:\socrates\build\ratatoskr\index.html

Open Ratatoskr
📊 Scientific Diagram Builder

Interactive tool for creating scientific diagrams, graphs, and charts for educational use across all courses.

Location: e:\socrates\build\diagram-builder\src\index.html

Open Diagram Builder

Quick Access Instructions

  1. Windows: Copy the file path and paste it into your browser's address bar
  2. File Explorer: Navigate to the path and double-click the HTML file
  3. Command Line: Use start command to open in default browser
